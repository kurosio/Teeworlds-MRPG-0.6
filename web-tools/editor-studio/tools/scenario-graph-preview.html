Scenario graph — one trigger, one flow

Every event block (on_end, on_recieve_objectives, on_equip, …) is started by the server as its own scenario, so a step can only link to steps of the same event. The graph paints each event with its own colour, lists them in the legend (click a chip to focus one) and never draws a wire across a boundary — the dashed “next step” arrows stop at the end of their block.
