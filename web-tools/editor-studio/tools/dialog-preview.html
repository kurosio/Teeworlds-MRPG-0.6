Dialogue editor — preview

Живая витрина модуля editor-core/dialog-editor.js: панель форматов, всплывающий выбор записи, чипы подстановок и порядок реплик. Данные — учебные, база не нужна.

  • «Bot / Item / World» над полем открывают список с поиском и вставляют <bot_12>, <item_31>, <world_3> в позицию курсора.
  • <player>, <time>, <here>, <eidolon> вставляются одной кнопкой — это значения, которые подставляет игра.
  • Чипы под полем показывают, что уже вставлено: клик по чипу меняет запись, крестик убирает формат, неизвестный ID подсвечен.
  • Справа в панели — длина реплики в байтах и лимит игры (1024). Порядок реплик — перетаскиванием, кнопками ↑/↓ или клавиатурой.
