Which tables of the current database sync with the target and in which direction. “Sync → target” is editor (CRUD) writes, “target → current” is the reverse load.

How it works: Every editor change (create, update, delete) is recorded in the history automatically. The “Sync” button in each editor checks schema compatibility and applies the accumulated changes to the target database. A full schema and data validation runs before applying.
Reverse sync: in the same “Sync” dialog you can replace the current database data with the target one (all tables except accounts). A dump of the current database is created automatically before loading.
